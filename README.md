Personal Website
This is my personal website, built completely from scratch using HTML, CSS, and JavaScript. It’s designed as both a digital portfolio and a creative space that reflects my interests in coding, reading, and education access. While practicing my front-end skills.
🌐 Overview
The website includes several main sections:
Home Page: Introduces who I am, my interests, and what inspired me to code.
Portfolio Page: Highlights my experiences, projects, and professional involvement in programs like Girls Who Code, Google Code Next, and HeadStart Fellowship.
Reading Corner: Features book recommendations, reviews, and a fun BuzzFeed-style quiz that helps users find which genre suits them best (Mystery, Romance, Fantasy, or Non-Fiction).
STEM 4 ALL Page: Shares free resources, scholarships, and opportunities for high school students interested in STEM, especially those from underrepresented backgrounds.
The site was built to combine both design and function, blending a “bookish warmth” aesthetic with clean, responsive layouts for readability and engagement.
🧩 Features
Fully responsive multi-page layout connected by a shared navigation bar
Custom color scheme and typography styled through CSS classes and IDs
Interactive quiz built with JavaScript that personalizes results based on user choices
Images with accessible alt text for inclusive design
Hosted on GitHub Pages for easy public access
